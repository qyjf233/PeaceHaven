用户画像 (bot_user_memory)

每个群聊成员的长期记忆档案。AI 回复时加载对方画像作为 Prompt 上下文，实现"了解对方"的效果。

人格维度 (learned_style_config)

从真实聊天中学到的核心风格参数，影响 System Prompt 中的人格描述。由 StyleLearningService 定时更新，也可在此手动覆盖。

表达档案 (persona_expression)

记录特色表达短语的频率、意图和使用疲劳度。高疲劳度的表达会被 Prompt 标记为"避免使用"。

关系画像 (persona_relationship_profile)

按联系人维护独立的交流风格画像。融合优先级：关系画像 > 场景画像 > 核心人格。真人是"看到某个人决定怎么说话"。

加载中...

场景画像 (persona_scene_profile)

按群聊类型维护交流风格。场景类型：friend_group / work_chat / family / private / stranger。融合优先级低于关系画像。

加载中...

当前状态 + 人格稳定性

当前状态（current_state_profile）：近 7 天的精力/压力/社交模式，作为 modifier 微调回复风格。
人格稳定性（persona_stability）：30 天内各维度变化幅度，高值 = 学习速度慢（防突变）。

学习快照 (persona_style_snapshot)

每次 StyleLearningService 定时学习产生的历史记录。用于 DriftDetector 对比 30 天趋势和效果回溯。仅支持删除（清理异常快照）。
